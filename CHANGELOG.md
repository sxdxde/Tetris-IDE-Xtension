# Changelog

## [0.1.0] — Initial release

- Highlights function declarations (full signature) and calls in a configurable color
- Supports JS, TS, JSX, TSX, Python, Java, C, C++, Go
- Arrow functions: variable name + `=>` both highlighted
- `tetris.highlightColor` setting with live update (no reload needed)
- Default color `#00FFCC` with 12% opacity background tint
